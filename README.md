## 快速上手：3 个立即可用的提示词心法

1. **先立人设再干活**：告诉 AI"你是《XX期刊》资深学术编辑"，输出立刻从"营销号腔"变"期刊味"

3. **负向约束**：明确告诉 AI"不要虚构文献、不要堆形容词、不要套话"，把它的坏习惯关掉
